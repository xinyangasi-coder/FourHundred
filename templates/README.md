# Chrome template

`chrome.html` is the one place to change footer links, the favicon tag, top nav, and the sheet-entry sentence.

Live pages were not bulk-rewritten against this file. New pages and Monday edits copy from here. If a live page disagrees with this file, this file wins.

Sheet sentence, when a sheet exists:

Open the one-page sheet — print it or fill it on paper. The sheet is the work. This page is the method.

Keep `build.py` HEADER and FOOTER aligned with `chrome.html`. Change `chrome.html` first.
