# Stripe Payment Links before upload

Create four Payment Links in Stripe. Then replace the four REPLACE_ strings in support.html. Do not push while those strings are still placeholders.

1. $5, $20, $100: one-time payment, fixed amount, no subscription.
2. Other amount: one-time, customer chooses the amount. Set a minimum of $1 if Stripe asks.
3. Turn off any wording that says donation or tax-deductible.
4. Do not collect a shipping address.
5. Copy each buy.stripe.com link over REPLACE_5, REPLACE_20, REPLACE_100, REPLACE_CUSTOM.
